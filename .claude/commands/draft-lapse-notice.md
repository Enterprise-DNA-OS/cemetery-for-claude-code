---
description: Draft a letter to the holder of a right of burial that is about to lapse, citing section 10(4) and the date.
---

Run `npm run cem -- draft-lapse-notice --right="<certificate, plot or holder>" --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Draft only. Check the address on file before it is posted.
