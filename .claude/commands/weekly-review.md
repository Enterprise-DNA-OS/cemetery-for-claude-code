---
description: The Monday review for the cemetery manager: this week's interments, last week's burials, capacity by section, rights lapsing, memorial permits waiting, accounts overdue and rule checks by rule.
---

Run `npm run cem -- weekly-review --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Write it as a one-page brief in this order: the numbers (interments this week, plots available, accounts overdue), the three things to decide this week, then each section in two or three lines. Save it to `drafts/weekly-review-<date>.md`.
