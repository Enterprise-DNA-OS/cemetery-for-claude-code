Run `npm run cem -- attention --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Lead with the next interment that is short of paperwork or the holder's consent: a family is waiting on that one. Then the register, then rights, then money, then grounds. For each line name the record, the rule and the next step, and offer the command that fixes it (paperwork, consent, assign-number, draft-lapse-notice, make-safe).
