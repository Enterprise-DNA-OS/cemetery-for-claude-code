---
description: Record a right of burial given back by agreement (s 10(3)), with an optional refund credited to the holder.
---

Run `npm run cem -- surrender-right --right="<certificate, plot or holder>" [--refund=<amount>] [--on=YYYY-MM-DD] [--note="…"] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.
