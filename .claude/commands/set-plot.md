---
description: Mark a plot unusable (with the reason) or usable again, or change how many interments it holds.
---

Run `npm run cem -- set-plot --plot="<plot>" [--unusable="<reason>"] [--usable] [--capacity=<n>] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

A plot with a right or interments cannot be marked unusable.
