---
description: Record a memorial permit application: plot, applicant (usually the monumental mason) and what is proposed.
---

Run `npm run cem -- apply-memorial --plot="<plot>" --applicant="<who>" --description="<material, size, wording>" [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.
