---
description: Approve or decline a memorial permit application.
---

Run `npm run cem -- decide-memorial --memorial="<id or plot>" --decision=approved|declined [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Check it against the section's rules (lawn sections often allow only a plaque on the beam) before approving.
