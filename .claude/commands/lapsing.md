description: Rights of burial that lapse under section 10(4) or reach the end of their term within the notice window, with space still in the plot.
---

Run `npm run cem -- lapsing --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Offer `draft-lapse-notice` for each holder who has not been written to.
