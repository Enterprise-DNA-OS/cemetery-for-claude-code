---
description: Record that the funeral director's burial paperwork is on file for a booking.
---

Run `npm run cem -- paperwork --booking="<deceased or id>" [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Only record it once the office holds the paperwork.
