---
description: Mark a booked interment done and enter it in the burial register with the next register number. Refused without paperwork, or without consent in a held plot.
---

Run `npm run cem -- complete --booking="<deceased or id>" [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Report the register number given.
