---
description: Record a memorial safety inspection: safe, leaning or unsafe.
---

Run `npm run cem -- inspect-memorial --memorial="<id or plot>" --condition=safe|leaning|unsafe [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

An unsafe memorial is a hazard to visitors and staff: cordon it or lay it down the same day, then write to the holder.
