---
description: Add a run of plots to a section: a row and a number range, burial or ashes, and how many each holds.
---

Run `npm run cem -- add-plots --section="<section>" [--row=<row>] --from=<n> [--to=<n>] [--type=burial|ashes] [--capacity=<n>] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Capacity is interments per plot: 2 for a double-depth lawn plot, 4 or more for an ashes plot.
