---
description: Move a booked interment to a new time.
---

Run `npm run cem -- reschedule --booking="<deceased or id>" --at=YYYY-MM-DDTHH:MM --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Offer `draft-confirmation` afterwards so the funeral director has the new time in writing.
