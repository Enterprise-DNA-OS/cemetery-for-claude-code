---
description: Add a section to a cemetery with its kind and fees.
---

Run `npm run cem -- add-section --cemetery=<name or code> --name="…" --kind=lawn|monumental|ashes|natural|children|services|denominational [--right-fee=<amount>] [--interment-fee=<amount>] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.
