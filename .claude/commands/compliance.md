---
description: Check the records against the Burial and Cremation Act 1964 and the house standards in docs/compliance.md, and report what is breached or about to be, with the section cited.
---

Run `npm run cem -- compliance --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Read `docs/compliance.md` first. Group by rule, breached first. Cite the section for each rule (s 10(2), s 10(4), s 50, s 51) or say it is a house standard. Offer the command that clears each line. Nothing here is legal advice: if a rule looks out of date, say so and stop.
