---
description: Record the date the holder of the right of burial consented to an interment in their plot (s 10(2)).
---

Run `npm run cem -- consent --booking="<deceased or id>" [--on=YYYY-MM-DD] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Only record consent the office has in writing.
