---
description: Record the removal of a body or ashes. Refused without the Minister's licence reference (s 51).
---

Run `npm run cem -- disinter --interment="<deceased or id>" --licence="<licence reference>" [--on=YYYY-MM-DD] [--destination="…"] --actor=<name>`.

This changes records. Get the real staff name for --actor. Run it with --dry-run first, show the operator what will change, and run it for real only after a yes in this session. Never invent a date, an amount or a person.

Never record a removal without the licence in hand. The register entry stays, marked removed.
